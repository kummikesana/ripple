# Ripple

Small choices, real ripples. A friendly, no-guilt web app for trying sustainable switches,
learning surprising facts, and seeing your impact across people, planet and prosperity.

## What's inside

- `index.html`: page structure
- `styles.css`: all styling, with light and dark mode
- `app.js`: the app (quiz, stages, small switches, tries, daily card, Did you know topics, garden)
- `favicon.svg`: site icon
- `vercel.json`: basic hosting settings

No build step and no dependencies. It's plain HTML, CSS and JavaScript.

## Run it locally

Open `index.html` in a browser, or run a tiny local server:

    npx serve .

## Deploy

1. Push this folder to a GitHub repository.
2. In Vercel, choose Add New > Project and import the repository.
3. Framework preset: Other. Leave build command and output directory empty.
4. Deploy.

## Data and privacy

Progress is stored only in each visitor's browser (localStorage). Nothing is sent to a server,
so there's no login and no personal data collected. Clearing browser data resets progress.

## Content

Facts and impact figures are rounded estimates from public sources (ADEME, UNEP, CDP, ESMA and others),
cited in the app. Career-topic facts were last checked in November 2026. Re-check them before
major updates, since regulations change often.
